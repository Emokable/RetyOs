# 2026-10-29 更新与验证范围

本轮在 Kindle Colorsoft、固件 5.20.1 上验证。仍为实验版本。

## 改动

- 接入原生 input_manager 的 kindle-input-pt 虚拟翻页键盘，保留原系统管理蓝牙配对。
- 修复虚拟设备能力过宽导致 Android 将键盘误识别为外接触笔的问题。
- 蓝牙翻页复用触屏的方向、动画开关与步数设置；用户确认翻页和动画正常。
- 冻结交接时释放并重新获取输入，丢弃旧队列并重置按键状态。
- 根据设备身份寻找触摸屏和电源键；不再依赖宿主固定 event 编号。
- 启动入口串行化，记录原生点击；退出中的启动请求等待上一轮退出完成。
- 无回收条件的旧目录、无项目镜像绑定的循环设备跳过不必要的全机扫描，保留实际回收前的安全校验。
- 退出脚本增加持久请求和控制器接收确认。
- 正常退出延迟刷新旧启动快照，交由原生界面接管；用户确认不再闪出启动页。
- 修复清理钩子的缩进匹配，并增加回归测试和只读输入诊断脚本。
