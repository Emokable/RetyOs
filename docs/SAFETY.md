# 设备脚本安全说明

`device/` 中的脚本会在 Kindle 上以 root 身份执行，可能停止/恢复 Kindle 图形服务、挂载容器文件系统、管理进程冻结和卸载镜像。它们只适用于对应的 Kindle Colorsoft 容器布局，不是通用维护脚本。

在设备上使用之前，应确认：

- 已备份 Android 数据镜像和重要 Kindle 用户文件。
- 有可工作的 SSH 或 Kindle 原生恢复入口。
- 当前没有 MTP 文件传输或镜像写入正在进行。
- 脚本所指向的目录、设备节点和固件版本与实际设备相符。
- 安装/升级包和回滚包由本地源码构建，并校验哈希。

此整理副本不包含可直接安装的二进制载荷；不能只复制脚本就启动容器。
